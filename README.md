## Complete syllabus

# Module 1 — Introduction to HTML
## What is HTML?
`
HTML stands for HyperText Markup Language. It is the language that gives web pages their structure and content.
`
## History and versions of HTML
Year	Milestone
- 1991	Tim Berners-Lee publishes the first description of HTML
- 1995	HTML 2.0, the first official standard
- 1997	HTML 4, with styles, tables, and forms
- 2014	HTML5 becomes a W3C recommendation, adding video, audio, canvas, and semantic tags

## How websites and web browsers work
- When you type a web address and press Enter:

    - The browser sends a request to a server, a computer that stores the website’s files.
    - The server responds with files, usually HTML, CSS, JavaScript, and images.
    - The browser reads the HTML and builds a structure called the DOM (Document Object Model).
    - The browser renders the page, drawing it on your screen.
## HTML vs CSS vs JavaScript
- HTML->Structure and content -> Walls, rooms, doors
- CSS->Appearance and layout -> Paint, furniture, decoration
- JavaScript -> Behavior and interaction -> Electricity, light switches

## HTML elements, tags, and attributes
- Opening tag `<p>`	-> Starts the element
- Content	`Welcome to my website.` -> What the user sees.
- Closing tag	`</p>` -> Ends the element (note the /)
- Attribute	`class="intro"`	-> Extra information about the element.
- Element -> the whole thing -> Opening tag + content + closing tag
- HTML5 and modern HTML standards


```
<!DOCTYPE html> → tells the browser HTML5
<html> → wraps the entire document
<head> → page information/metadata
<title> → browser-tab title
<body> → visible page content
<h1>–<h6> → headings
<p> → paragraphs
<br> → line break
<!-- --> → comments
Indentation → makes your code readable
```
